# 🛒 Dimenzn Shop

A modern, full-stack e-commerce platform built with **Vue 3**, **Quasar Framework**, and **Node.js**.

Dimenzn Shop is designed to be a highly scalable, internationalized store featuring advanced product variations, dynamic categorization, and a completely custom-built web installer that makes deployment and setup effortless.

## ✨ Key Features

- 🚀 **Web-Based GUI Installer:** No need to manually configure `.env` files. On the first run, the app guides you through a UI to securely connect your MongoDB database and initialize the system.
- 📦 **Advanced Product Variations:** Full support for granular inventory tracking, including size-specific stock and global quantities.
- 🗂️ **Dynamic Categorization:** Deeply nested category and sub-category routing.
- 🌍 **Fully Internationalized (i18n):** Built from the ground up to support multiple locales and languages across all products, UI elements, and database entries.
- 🌱 **Automated Seeding:** Built-in seed generation to populate the database with realistic mock ads, nested categories, and randomized products for quick development.
- 🎨 **Sleek UI/UX:** Powered by Quasar, offering a highly responsive, app-like experience on both mobile and desktop.

## 🛠️ Tech Stack

**Frontend:**

- Vue 3 (Composition API)
- Quasar Framework
- Pinia (State Management)
- Axios

**Backend:**

- Node.js & Express.js
- MongoDB & Mongoose
- PM2 / Nodemon (Process management)

## 🚦 Getting Started

### Prerequisites

Make sure you have the following installed on your machine:

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- [MongoDB](https://www.mongodb.com/) (Local instance or MongoDB Atlas cluster)
- `npm`, `yarn`, or `pnpm`

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Dimenzn/shop.dimenzn.open.git
cd shop.dimenzn.open
```
